# Artigo 17.º — (Estacionamento paralelo à faixa de rodagem)

Quando o estacionamento nas zonas de estacionamento de duração limitada se faça sob a forma de estacionamento paralelo à faixa de rodagem:

a) Os lugares de estacionamento para veículos ligeiros têm a dimensão de 5m x 2,10m;

b) Os lugares de estacionamento para os veículos pesados têm a dimensão de:

i. Para os pesados de mercadorias-14,5 m x 3m;

ii. Para os pesados com semirreboque -17mx3m.
