# Artigo 3.º — (Definição do SI)

1. O SI é o sistema métrico decimal baseado nas seguintes unidades básicas de medida, usadas de forma padronizada:

a) O metro (m), unidade básica de comprimento;

b) O quilograma (kg), unidade básica de massa;

c) O segundo (s), unidade básica de tempo;

d) O ampere (A), unidade básica de corrente elétrica;

e) O kelvin (K), unidade básica de temperatura termodinâmica;

f) A candela (cd), unidade básica de força da luz;

g) O mole (mol), unidade básica de quantidade de matéria.

2. As unidades básicas de medida legais do SI mencionadas no número anterior encontram-se definidas no anexo ao presente diploma.
