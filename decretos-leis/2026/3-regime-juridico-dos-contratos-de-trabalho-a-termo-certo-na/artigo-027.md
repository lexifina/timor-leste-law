# Artigo 27.º — (Responsabilidade)

1. O administrador de contratos é responsável pela gestão dos contratos, e os superiores hierárquicos das unidades de trabalho beneficiárias são os responsáveis pela gestão de desempenho dos contratados.

2. O administrador de contratos é nomeado pelo superior hierárquico relevante e pelo serviço de recursos humanos para gerir os contratos dos contratados.
