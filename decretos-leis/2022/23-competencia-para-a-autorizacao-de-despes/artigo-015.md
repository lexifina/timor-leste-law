# Artigo 15.º — (Estatuto Remuneratório dos Diretores Adjuntos)

1. Os Diretores Adjuntos são equiparados, para efeitos remuneratórios, a Diretores Nacionais.

2. Os Diretores Adjuntos têm direito a receber os suplementos remuneratórios legalmente previstos para os dirigentes da Administração Pública.
