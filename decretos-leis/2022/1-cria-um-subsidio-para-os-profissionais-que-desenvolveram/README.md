# Decreto-Lei n.º 1/2022, de 5 de janeiro

Cria um subsídio para os profissionais que desenvolveram atividade jornalística solicitada pelo Governo para fornecer notícias sobre o vírus SARS-Cov2 durante o estado de emergência

- Publicado / published: 2022-01-05, Jornal da República (<https://www.mj.gov.tl/jornal/public/docs/2022/serie_1/SERIE_I_NO_2.pdf>)
- Em vigor / in force: 2022-01-06 — "entra em vigor no dia seguinte ao da sua publicação"
