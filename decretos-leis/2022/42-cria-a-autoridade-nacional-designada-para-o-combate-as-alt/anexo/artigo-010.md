# Artigo 10.º — (Órgãos)

1. São órgãos da AND:

a) O Presidente;

b) O Fiscal Único;

c) O Conselho Consultivo;

2. Para cada projeto sobre alterações climáticas é criado um comité específico, designado por Comité Especial para o Financiamento em Matéria de Alterações Climáticas, cuja composição e competências são definidas no presente diploma.
