# Resolução do Governo n.º 14/2023, de 5 de abril

Determina, para o ano de 2023, os escalões das pessoas coletivas públicas e serviços personalizados abrangidos pelo Decreto-Lei n.o 92/2022, de 22 de dezembro, para o efeito de determinação das remunerações dos titulares dos seus órgãos
