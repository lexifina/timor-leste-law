# Artigo 8.º — (Métodos de aprovisionamento)

1. Os métodos de aprovisionamento a utilizar são definidos de acordo com o valor estimado dos bens a adquirir, da seguinte forma:

a) Quando o valor estimado dos bens a adquirir for inferior a USD 200,00 (duzentos dólares americanos), o Administrador do Posto Administrativo aprova os fornecedores com base na cotação de uma só empresa;

b) Quando o valor estimado dos bens a adquirir for superior a USD 200,00 (duzentos dólares americanos), o Administrador do Posto Administrativo aprova os fornecedores tendo por base uma consulta a pelo menos três empresas.
