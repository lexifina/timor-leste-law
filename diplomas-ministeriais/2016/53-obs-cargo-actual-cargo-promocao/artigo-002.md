# Artigo 2.º — (Concessão)

1. Pelo presente Diploma são autorizadas duas Concessões, uma para Dili, outra para o restante território de Timor-Leste, para a atribuição do licenciamento da exploração de slot machines, pelo prazo de 30 dias a contar da publicação do presente diploma.

2. Cada uma das Concessões referidas no número anterior,obedece a um número máximo deslot machines a determinar pela Inspecção-Geral de Jogos (IGJ), com base nos processos de candidatura apresentados.

3. O prazo máximo das Concessões é fixado no despacho de autorização de licenciamento da exploração de slot machines.
