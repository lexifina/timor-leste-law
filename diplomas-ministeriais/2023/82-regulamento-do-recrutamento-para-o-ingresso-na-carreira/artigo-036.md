# Artigo 36.º — (Correção das provas)

1. Sempre que possível, a cada requerente é atribuído um código, de modo a assegurar a imparcialidade durante a correção.

2. A correção é antecedida de produção de grelhas de respostas às questões das provas.

3. Compete ao júri a correção das provas, podendo, para o efeito, fazer uso de meios de tecnologia de informação para auxiliar na correção e fazendo uso da grelha de respostas prevista no número anterior.

4. Os resultados da correção das provas são expressos numa escala de 0 a 100 valores.
