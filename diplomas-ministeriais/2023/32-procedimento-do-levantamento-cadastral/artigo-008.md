# Artigo 8.º — (Processamento de Dados Cadastrais)

1. Os dados técnicos recolhidos por meio de levantamento cadastral, tanto o esporádico quanto o sistemático, são processados utilizando o programa especifico denominado Leica Geo Office (LGO) e outros programas considerados adequados.

2. A planta cadastral é desenhada com o software Autocad.

3. Para a elaboração do mapa cadastral far-se-á uso de programas, como ArcGis, Qgis e outros programas adequados.
