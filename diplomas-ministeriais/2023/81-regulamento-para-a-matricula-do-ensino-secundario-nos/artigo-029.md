# Artigo 29.º — (Registo da matrícula na base de dados da educação)

1. As listas finais de matrículas, conjuntamente com o formulário de pedido de matrícula e os demais documentos exigidos, são remetidas para o serviço central responsável pelos dados da educação do departamento governamental responsável pelo ensino secundário.

2. São registados na base de dados da educação as crianças e jovens matriculados no ano escolar de acordo com a lista final de matrícula aprovada pelo dirigente do estabelecimento de ensino secundário.

3. Cada criança ou jovem é registado individualmente na base de dados da educação, o qual contém os dados pessoais relevantes contidos no formulário de pedido de matrícula, sendo atribuído a cada aluno um número identificador único.

4. O identificador único é o mesmo do ensino básico, caso exista.
