# Artigo 14.º — (Estrutura orgânica)

A DNRH possui os seguintes serviços de apoio:

a) Departamento de Gestão de Recursos Humanos;

i. Seção de Pagamento payroll;

ii. Seção de Avaliação de Desempenho;

iii. Seção de Base de Dados e controlo de assiduidade

b) Departamento de Planeamento e Formação;

i. Seção de Atendimento

ii. Seção de Planeamento

iii. Seção de Verificação de Dados

c) Departamento de Mapa de Pessoal.
