# Artigo 40.º — (Estrutura orgânica)

A DNTI possui os seguintes serviços de apoio:

a) Departamento de Infraestrutura Tecnológica Informática;

i. Seção de engenharia de rede

ii. Seção de administração de rede

iii. Seção de analista de segurança cibernética

b) Departamento de Serviço de Apoio Técnico Informático;

i. Seção de controlo do servidor e armazém de IT

ii. Seção de Hardware e resolução de problemas

iii. Seção de instalação de Sofware e sistema de resolução de problemas

c) Departamento de Sistema de informação e Base de Dados

i. Seção de Desenvolvimento e Programação

ii. Seção de Base de Dados e Análise

iii. Seção de Design Gráfico e Multimédia.
