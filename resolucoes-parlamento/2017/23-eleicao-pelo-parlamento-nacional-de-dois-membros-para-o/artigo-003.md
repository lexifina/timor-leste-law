# Artigo 3.º — (Classificação das atividades económicas)

1. As atividades económicas são classificadas segundo uma análise feita com base no risco para os consumidores e para o ambiente, em atividades económicas de baixo, médio e alto risco.

2. A lista de atividades económicas de baixo risco consta do anexo I ao presente Decreto-lei dele fazendo parte integrante.

3. A lista de atividades económicas de médio risco consta do anexo II ao presente Decreto-lei dele fazendo parte integrante.

4. A lista de atividades económicas de alto risco consta do anexo III ao presente Decreto-lei dele fazendo parte integrante.
