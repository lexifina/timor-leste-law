# Artigo 60.º — (Anúncio para pré-qualificação)

O anúncio para pré-qualificação contém os elementos previstos no n.º 2 do artigo 51.º, bem como, em substituição dos elementos enumerados nas alíneas o) a q) desse número:

a) Os requisitos mínimos de capacidade técnica, legal, comercial e ou financeira que os candidatos devem preencher;

b) Os documentos necessários para comprovar a qualificação dos candidatos;

c) O número de candidatos a qualificar, caso se preveja a qualificação de um número máximo de candidatos, bem como o modelo de avaliação das candidaturas;

d) O prazo para a apresentação das candidaturas;

e) O prazo para a decisão de qualificação;

f) O prazo para a apresentação dos documentos comprovativos do cumprimento dos requisitos mínimos de capacidade técnica e financeira, caso estes possam ser apresentados após a decisão de qualificação.
