# Artigo 148.º — (Mapas cadastrais)

1. A Autoridade Reguladora, em coordenação com os Ministérios competentes, deve elaborar, para cada Município, mapas cadastrais relativos aos Direitos Mineiros, que contenham as referências topográficas específicas dos limites de cada perímetro das áreas sobre as quais tenham sido atribuídos Direitos Mineiros ou os respetivos pedidos se encontrem pendentes, os quais fazem parte do Registo Mineiro.

2. Os mapas cadastrais devem estar disponíveis para consulta pública.
